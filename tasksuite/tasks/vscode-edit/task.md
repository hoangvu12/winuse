Start VS Code opening the project folder by running this command:

    code "{{.ScratchDir}}\project"

If VS Code asks whether you trust the authors of this folder, choose the
option that lets you work with it. If a welcome page or tour opens,
close it.

In the project folder, create a new file named "checklist.md"
containing exactly:

Setup checklist

- confirm the display cable is seated
- label the two spare SSDs
- update the meeting room calendar

Save the file, then close VS Code.
