---
title: Create a ZIP archive of the report files
category: ordinary
tags: selection, context-menu, archive
apps: explorer
---

Open File Explorer showing the folder "{{.ScratchDir}}\Reports" (for
example by running: explorer "{{.ScratchDir}}\Reports").

Select the three .txt files in the folder and create a ZIP archive from
the selection (right-click > "Compress to ZIP file", or the equivalent
the system offers). Name the archive "reports.zip" (rename it if the
system gives it a different name) and leave it inside the Reports
folder.

Close the Explorer window when you are done. The three original files
must remain in the folder.
