---

Open File Explorer showing the folder "{{.ScratchDir}}\Invoices" (for
example by running: explorer "{{.ScratchDir}}\Invoices").

In that folder:

1. Create a new folder named "2024".
2. Move all six invoice files (invoice-2024-01.txt through
   invoice-2024-06.txt) into the 2024 folder.
3. Rename draft-summary.txt to summary.txt.
4. Leave notes.txt where it is.

Close the Explorer window when you are done. Everything must stay inside
the Invoices folder, and the files' contents must not change.
