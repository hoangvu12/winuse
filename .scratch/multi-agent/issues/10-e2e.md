# 10: Opt-in e2e for several agents

**What to build:** e2e tests that run two agents at once through the CLI, with `WINUSE_AGENT=a` and `WINUSE_AGENT=b`.

- Two covered fixtures: agents a and b click and set values at the same time. Both succeed, the foreground is unchanged, and the overlap in time is measured (parallel, not serial).
- Same fixture: a reads, b reads, a clicks by index. a's Element is acted on.
- A Headed Action from a while b waits for the desktop lane: b gets the wait, then runs; with a short limit, b gets "nothing was sent".
- Esc during both: both stopped. Needs `WINUSE_E2E_HUMAN=1`, as the existing Esc test does.
- A hung fixture (ticket 07's mode) does not delay the other agent's click.
- Write and compile; live runs follow the usual one-at-a-time rule.
