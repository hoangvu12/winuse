# 03 — The Agent Cursor

**What to build:** a per-pixel-alpha, click-through, topmost, never-activated layered window on the overlay's UI thread: an arrow cursor and a label pill that travel to the Element's centre (eased, ~300 ms) before each Headless Action, then a ripple and a brief outline of the Element's bounds. Starts at the target Window's centre, fades after 6 s idle, hidden around winuse's own captures, best effort. API in screen rectangles and label text only. See spec: Agent Cursor.
